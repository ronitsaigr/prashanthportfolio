# Public-safe implementation specification

## Phase 0
Isolated Astro, strict TypeScript, Tailwind and Cloudflare Worker foundation, quality checks, preview deployment, separate D1 environments. No production cutover.

## Phase 1
Public home, services, training, case studies, demos, about, book, contact and policies. Validated enquiries with consent, source attribution, bot protection, database persistence, reliable signed event delivery and notifications. SEO and accessibility. Do not publish private details or unreviewed legal terms.

## Phase 2
Revenue leak scorecard, authenticated CRM, contacts, deals, activities, dashboard and CSV exports. Verify Cloudflare Access JWT server-side; retry failed notifications and support booking signals.

## Phase 3
Workshops and verified payment flows, refunds, coupons, partner attribution and aggregate-only partner portal, certificates and verification. All financial rules server-side and tested. Test mode before live payments.

## Phase 4 (explicit owner request only)
Content, multilingual pages, proposals, invoicing and client portal.

Security: never trust client prices or unverified webhook requests; keep environment secrets separate; use least-privilege access; integer paise and UTC timestamps. No paid services without review. The owner maintains the complete private business specification separately.
